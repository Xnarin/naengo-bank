# 계좌 정지 요청이 카드 정지로 연결되는 문제

2026-11-11 제보: “계좌 정지하고 싶어”에 보유 체크카드 일시 정지 확인 화면이 표시됐다.

계좌 정지는 챗봇에서 지원하지 않는다. 명확한 계좌·통장 정지 요청은 모델 분류 전에 서버가 구분해 지원 범위와 계좌 해지 화면의 위치를 안내한다. 카드 처리 노드에도 같은 검사를 둬 계좌 정지 문장으로 카드 확인창을 만들지 않는다. 계좌를 실제로 정지하거나 해지하지 않는다.

표시 문구: “계좌 정지는 챗봇에서 지원하지 않아요. 계좌를 없애려는 뜻이라면 홈에서 해당 계좌의 관리 화면으로 들어가 ‘계좌 해지’를 이용해 주세요.”

회귀 테스트는 계좌 정지·통장 일시 정지·계좌 막기·카드 말고 계좌 정지의 네 문장을 모델 없이 안내하는지, 확인 ID가 없는지, 계좌와 카드가 정상 상태를 유지하는지 검사한다. 카드 노드를 직접 호출해도 안내만 반환한다. 반대로 “계좌에 연결된 끝자리 4821 카드 정지해줘”는 기존 PIN 승인 대기 화면을 표시하며 승인 전에는 카드 상태를 바꾸지 않는다.

운영 금융 상태를 변경하는 테스트는 실행하지 않는다. 자연어 전체를 정규식으로 판별하는 것은 아니며, 그 밖의 표현은 계좌 정지를 별도 의도로 구분하도록 모델 분류 기준에도 반영했다.
